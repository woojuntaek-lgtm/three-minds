# 마음의 세 자리

정필 관법 2편 「좋은 조언을 듣고도 왜 안 바뀔까: 근본심·생동심·정동심」의 부록 앱입니다. 1편과 같은 가상 명조(병진년 계사월 갑술일 신미시)로 근본심(시간)·생동심(월간)·정동심(일지) 세 자리를 짚어 보고, 육신으로 읽는 다섯 마음, 근본심에 정이 놓일 때와 편이 놓일 때 쓰는 법, 생동심을 다루는 두 가지 반응, 사생왕고(생지·왕지·고지), 음력 생일 일자로 정하는 일지 지장간 사령과 직업의 마음(임수·인목 예 포함), 그리고 내 출생 시각으로 세 마음과 그 일치 여부를 읽는 계산기를 담았습니다. 파일 하나(`index.html`)로 인터넷 없이 동작합니다.

## 구성
- ① 세 자리: 근생정동심, 육신으로 읽는 다섯 마음
- ② 근본·생동: 정과 편의 쓰는 법, 생동심 다루기
- ③ 정동심: 사생왕고, 지장간 사령
- ④ 내 명조: 세 마음 읽기 계산기, 오늘의 핵심

## 계산 기준
- 절기·간지는 정필 만세력과 같은 절기표(1900~2100), 음력은 한국천문연구원 기준 음력표(1900~2050)를 씁니다. 태양시 보정은 1편과 같습니다.
- 일지 사령은 원고의 가상 명조처럼 음력 생일 일자를 지장간 일수(월률분야) 순서에 맞춰 정합니다. 예: 술토 신1~9일·정10~12일·무13~30일.
- 근본심의 정·편은 원고의 정관·정인/편관·편인을 따르고, 비겁·식상은 일간과 음양이 다르면 정(겁재·상관), 같으면 편(비견·식신) 쪽으로 나눴습니다.
- 세 마음의 일치는 육신의 갈래(비겁·식상·재성·관성·인성)가 같은지로 봅니다.

사례는 모두 가상 명조입니다. 입력한 출생 정보는 저장하거나 보내지 않습니다. 해석은 공부용 참고입니다.
